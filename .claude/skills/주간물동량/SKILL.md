# 주간물동량

이 파일이 측심 주간 루틴의 유일한 동작 정의다. 오너 위임문(2026-09-24)에서 났다.
판정 기준은 `docs/측심_주간루틴_판정기준_선커밋_20260924.md`(고치지 않는다 — 재판정은 다음 위임문).

## 목적

인천항 컨테이너 물동량을 주 1회 잰다. 축은 **컨테이너 물동량 하나**다 — 무역·유통으로 넓히지 않는다
(`CLAUDE.md` §「이 프로젝트가 무엇인가」와 같은 경계).

## 실행

- 루틴, 모델 Opus. 주기: 주 1(권장 월요일 06:00 KST).
- 브랜치: 실행 환경이 배정한 `claude/` 브랜치를 그대로 쓴다, PR만 — main에 직접 push 안 한다
  (기존 세션의 「push·배포는 세션이 친다」 위임과 갈라진다 — 이 루틴은 **PR로만** 낸다. 판정 기준 1이 그 이유다).

## 하는 일

1. `git rev-parse HEAD` · `docs/STATUS.md` 확인 — 통상 개시 의례.
2. `python analysis/collect_terminal_monthly.py --limit 2`로 최신월을 확인한다.
   `analysis/terminal_monthly_long.csv`의 마지막 월과 비교해 **새 월이 있는가**를 가른다.
3. **새 월이 있으면**: 데이터 갱신 — `terminal_monthly_long.csv`·`terminal_monthly.csv`에 새 행 추가,
   `reports/물동량.md`의 헤드라인·12개월 추이·터미널별 표를 재생성, 필요시 공컨 방향 데이터도
   (`analysis/container_20XX_direction.csv`) 같은 절차로 갱신. `docs/FACTS.md`에 새 값 등재.
4. **새 월이 없으면**: `reports/물동량.md`가 이미 다루는 단면 중 **이번 주에 아직 안 쓴 것**을
   하나 골라(수출입 비율 / 터미널별 몫 변화 / 공컨 비율 추이 등 — 순서는 세션 판단, 같은 단면을
   2주 연속 쓰지 않는다) 그 단면으로 숫자 하나 + 해석 한 줄을 새로 뽑는다. 페이지 본문은 그대로 둬도 된다.
5. 링크드인 게시 초안 1건 작성 — 숫자 하나 + 해석 한 줄 + 사이트 링크, 한국어, 3~5문장, 800자 안팎
   (기존 li-* 문안 관례). **이 루틴의 초안은 본부가 아니라 `docs/채널문안/<YYYY-MM-DD>.md`에 저장한다**
   (위임문의 명시적 결정 — 자기 서술·공개 수치뿐이라 §4.1의 「상대의 말」 경계와 다르다).
   `docs/채널대기열.md`에 새 행 추가(상태 `준비`).
6. `python analysis/lint_publish.py` · `check_facts.py` · `check_claims.py` · `check_refs.py` ·
   `check_links.py` · `check_jekyll.py` · `check_a11y.py` · `check_counts.py` 통과 확인.
7. 전부(데이터 + 페이지 + 채널문안 + 대기열 행)를 **커밋 하나 또는 논리적으로 묶은 몇 개**로,
   **PR 하나**로 올린다. PR 본문에 그 주 무엇이 바뀌었는지(새 월 갱신 vs 단면 전환)와
   사람 손 목록(링크드인 클릭)을 적는다.
8. 사람 손: 로그인·게시 버튼은 다루지 않는다 — PR 머지 뒤 오너가 `docs/채널문안/`의 파일을
   보고 직접 게시하고 `channel_queue.py --set --state 게시됨 --url`로 닫는다.
   **측심 라이브 사이트(sounding.higgsfield.app)로의 반영은 이 루틴의 몫이 아니다** — 그 저장소는
   별도이고 `repo-access` 토큰 갱신이 오너 전용이다(지침 §4 가). 인천 Pages(이 저장소) 갱신만으로 끝낸다.

## 성공/폐기 기준

8주(게시 8건) 안에 업계 반응 0건이면 단면·형식을 바꾸되 갱신은 멈추지 않는다.
오너 시간이 2주 연속 15분을 넘으면 다음 위임문에서 산출물 분량을 줄인다.

## 금지

- 국가별(수입국·수출국) 단면 — 공식 출처가 아직 없다. 비공식 출처로 채우지 않는다.
- "종합" 확장 — 무역·유통·타 항만으로 넓히지 않는다. 다음 축은 3개월 뒤 판정 후 별도 위임문.
- 새 유료 도구·API 키 종량 도구 도입.
- 링크드인 로그인·자동 게시·계정 대리 조작.
- main 직접 push — 이 루틴은 PR만.
