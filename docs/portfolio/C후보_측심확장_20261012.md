# portfolio 후보 카드 — 측심 C 후보 넷 (발굴실 행 · 2026-10-12)

> 선장님 10/10 위임: C 후보(영어판 · 검색어별 페이지 · 데이터 절약 모드 · 측심 성과판)는 **카드 한 장으로만** 남겨 발굴실에 넘긴다. 이 세션은 만들지 않았다.

| 후보 | 한 줄 | 무엇이 먼저 서야 하나 | 예상 비용 | 판정 질문(발굴실이 답할 것) |
|---|---|---|---|---|
| 영어판 | 인천 물류 숫자를 영어로(해외 셀러·포워더·연구자) | 보고서 ①층 결론·갱신일 구조(1단계 완료) · 용어 대역표 | 편당 번역·검수 · 유지 비용이 편 수에 비례 | 영어 독자가 실제로 오나(Cloudflare 국가 분포 28일) |
| 검색어별 페이지 | 「3PL 견적 비교」「인천 물류창고」 같은 검색어마다 답형 지면 | sitemap·구조화 데이터(완료) · 검색어 실측(Search Console) | 낮음 — 기존 도구·보고서 재조립 | 검색 유입이 계산기 사용으로 이어지나 |
| 데이터 절약 모드 | 영상·3D·글꼴을 끄는 가벼운 판 | 이미 `Save-Data`·움직임 줄이기면 히어로 영상을 안 붙인다 | 낮음 | 모바일 저속 방문 비율이 의미 있나 |
| 측심 성과판 | 방문·계산기 사용·크몽 클릭·릴스 클릭을 한 장에 | Cloudflare 분석(설치됨) · `/go/` 클릭 지면(설치됨) · 28일 재검토(확장 기준 29) | 중간 — 공개냐 비공개냐에 따라 | 공개가 신뢰를 올리나, 비교 대상(경쟁 계정)에 신호를 주나 |
