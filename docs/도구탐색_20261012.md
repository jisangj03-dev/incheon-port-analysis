## MoneyPrinterTurbo 상세 (`git clone` 후 읽기만 · 실행 안 함)
- **LLM 키 없이**: `video_script` 와 `video_terms` 를 **둘 다** 직접 넣으면 LLM 호출을 건너뛴다(대본·검색어는 Claude 가 넘긴다 — 다른 AI API 키 금지 조건 충족 가능).
- **Edge TTS 의존**: `edge_tts==7.2.7` 이 기본 음성 경로다 → 선장님 방침대로 **끈다**(자막만 또는 vidIQ 공식 음성 파일을 넣는다). 코드 수정 또는 설정으로 TTS 를 건너뛰는 경로가 있는지는 실행 시험에서 확인한다.
- **기본 BGM**: `resource/songs` mp3 29곡, 곡별 라이선스 [미확인] → **제외**(선장님 방침).
- **영상 소스**: Pexels 기본 · Pixabay 지원 — Pixabay 키는 선장님 발급 후 환경 변수.
- **pip-audit 2.10.1**: 취약점 7줄 · 2개 패키지 — python-multipart 0.0.27(수정 0.0.30~0.0.31) · litellm 1.86.2(수정 1.88.6+). **requirements 를 그대로 쓰지 않고 두 패키지를 올린 뒤 다시 audit** 하는 것이 도입 조건.
- 결론: **이번 세션은 판정까지.** 실행 증명은 Pixabay 키와 함께 Actions(무료 연산)에서 — 다음 세션 위임문(`docs/위임문_다음세션_20261012.md`)에 넣는다.
