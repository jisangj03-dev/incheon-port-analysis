## P1 — 도구 정확도(각 도구 「한계」 칸을 줄인다)
**⑤ 뉴스레터 「차단됨」** — 성공: 원인 판정(미리보기 샌드박스 vs 공개판) · 구독 링크 = 새 창(`target=_blank rel=noopener`) 외부 링크 · 공개판 빌드에서 `/go/newsletter.html` → beehiiv 가 막히지 않음(시험: 링크 속성 · 돌려보내기 지면 200). 미리보기 탓이면 띠에 한 줄. 폐기: 없음.
**② 환율·수입원가** — 성공: 표 숫자가 열 제목과 같은 정렬(가운데 · 시험 = 머리칸과 숫자칸 가운데 x 차 ≤ 2px) · **HS 코드 입력 → 관세율표 자동 채움**(관세청 관세율표 공공데이터 · 기본·WTO·FTA 협정세율 · 빌드 때 스냅샷 · 키는 Actions) · 원산지증명 유무 선택(협정세율 적용 여부) · 개별소비세·교육세·주세·농특세 해당 품목 반영 · 과세가격 원 미만 처리 = 관세법(절사 규정 인용) · 「적용 환율 = 수입신고일이 속한 주」 명시 · 부가세 = 납부 합계/원가 분리(#57 끝) · 통관수수료·보험료 기본값과 출처 · **관세사 실무 표본 3건 이상 원 단위 일치 시험**. 폐기: 관세율표 데이터를 공식 경로로 못 받으면 HS 자동 채움을 미달로 두고 직접 입력 유지(표본 검산 시험은 그대로).
**① 등시선** — 성공: 시간대(출근 7–9 · 낮 · 야간)별 **실측 통행속도**(국가교통정보센터·지자체 소통정보 등 공공데이터 · 빌드 때 · 키 필요하면 신청서 초안 + 선장님 손) · 화물차 기준(고속도로 최고속도 · 통행제한) · 상하차 준비시간 입력 · **표본 OD 30쌍 이상을 내비 경로시간과 대조해 오차(중앙값·90%)를 방법론에 공개**(대조값은 채팅이 TomTom 커넥터로 뽑는다 — OD 목록을 인계에). 폐기: 실측 속도를 못 받으면 지금 가정 속도 유지 + 「가정」 표기 + 대조 오차만 공개.
**③ 초크포인트** — 성공: 국가별 교역에서 **항공 화물을 빼고 해상분만**(관세청 운송수단별 통계) · 항로 배정 = PortWatch 통항 실측 + 국가·항로 규칙 공개 · 품목(HS) 단위 노출 · 우회 시 추가 일수·운임(KCCI) 충격. 폐기: 운송수단별 통계를 못 받으면 「항공 포함 — 반도체 등은 부풀려짐」 표기 강화.
**④ 위성 묘박지** — 성공: 묘박지 구역 확대 · **Sentinel-1 SAR 로 선박 검출**(구름 무관 · 배마다 원 · 척수) · 날짜별 척수 그래프 · Sentinel-2 는 실사 배경 · 넘김 = 크로스페이드·슬라이더 · 미리 불러오기. 폐기: SAR 를 무료·키 없이 Actions 에서 못 받으면 S2 검출 유지 + 「구름 낀 날 제외」 표기.
