## 채팅이 처음 표에서 고친 것
- **Metricool은 링크드인 홍보에 쓰지 않는다.** 확인해 보니 Metricool 브랜드는 '무슨사이' 하나뿐이고 연결 채널도 FB·IG·Threads다. 링크드인을 붙이려면 무슨사이 브랜드에 섞거나 브랜드를 하나 더 만들어야 하는데, 후자는 유료 요금제 가능성이 있다(헌법 5). 링크드인은 지금처럼 채팅이 초안을 채워 두고 선장님이 게시를 누른다.
- **Lighthouse 점수는 홍보 근거가 아니라 회귀 감시용이다.** 접근성·SEO가 이미 100이라 개선 폭이 없다(선커밋 문서 기준선).
