## 2. 선커밋 판정 기준 (파일을 열기 전)

- **P1 범위**: 인천광역시(옹진·강화 포함) 행만 쓴다. 인천 행이 0이면 「없음」으로 적고 멈춘다(분모 0은 통과가 아니다).
- **P2 단위·합계**: 면적 단위(㎡/천㎡)를 원본 표기로 확인한 뒤 합산한다. 합계 행 = 행 합 검산이 맞지 않으면 FAIL.
- **P3 중복**: 명칭+주소 기준 중복 행 0. 있으면 제거 수를 기록한다.
- **P4 교차(대조 10건)**: 임의 10건을 해당 지자체·국가물류통합정보센터 화면과 맞대어 일치 10/10. 못 맞대면 「미확인」.
- **P5 신선도**: 수정일이 12개월보다 오래되면 본문 첫 줄에 기준일을 적는다.
- **P6 공개 범위**: 시설명·주소는 공공 시설 정보라 개인정보 열은 없을 것으로 보나 **[미확인]** — 열 목록을 먼저 보고, 대표자·전화 등이 있으면 산출 경로에서 뺀다. 이용허락이 「제한 없음」으로 확인돼도 원본은 올리지 않고 집계(구별 개소·면적 합)를 올린다.
- **P7 해석 한계**: 인천 물류단지·터미널의 분포·규모만 말한다. 입주율·가동률·전망은 이 원천에 없어 말하지 않는다.
