# 주소→좌표 키 발급·등록 안내 (오너용 · 2026-09-30)

> 키 셋 중 **꼭 필요한 것은 도로명주소 둘**이고 브이월드는 선택이다.
> **어느 단계에서든 결제수단(카드·계좌) 입력 화면이 나오면 멈추고 세션에 알려 달라** — 위임문의 멈춤 조건이다.
> **키 값은 채팅·PR·커밋 어디에도 붙이지 않는다.** 아래 「넣을 곳」 두 군데에만 넣는다.

## 왜 도로명주소가 주력이 됐나 (한 단락)

브이월드 지오코더 API 2.0 레퍼런스에 「API 요청은 실시간으로 사용하셔야 하며 **별도의 저장장치나 데이터베이스에 저장할 수 없습니다**」라는 문구가 있다.
좌표를 저장소에 캐시하는 이번 설계와 맞지 않는다. 그래서 **저장하는 좌표는 행정안전부 도로명주소 좌표제공 API**에서 받고,
브이월드는 무작위 표본의 **거리 대조에만 실시간으로** 쓴다(결과를 어디에도 안 쓴다). 경위 = `docs/주소좌표_판정기준_선커밋_20260930.md` 끝 절.

## 1. 도로명주소 — 필수, 승인키 두 개

**사이트**: 주소기반산업지원서비스 `https://business.juso.go.kr` → 상단 「API 신청」(또는 「API 신청하기」).
**한 번에 하나씩 두 번 신청한다** — 1 시스템 1 승인키라 API 종류가 다르면 키도 다르다.

| 신청 | API 종류 | API 유형 | 넣을 변수 |
|---|---|---|---|
| ① | **도로명주소** | **검색API** (팝업API 아님) | `JUSO_SEARCH_KEY` |
| ② | **좌표제공** | **검색API** (팝업API 아님) | `JUSO_COORD_KEY` |

**입력 칸 문구(그대로 붙여도 된다)**
- 시스템명: `측심 인천 물류시설 좌표 변환`
- 서비스 URL(또는 사이트 주소): `https://jisangj03-dev.github.io/incheon-port-analysis/`
- 서비스 용도: **개발** 으로 먼저 받는다(신청 즉시 발급). 운영 전환은 첫 배치가 기준을 넘은 뒤에 한다 — 운영 전환은 본인인증을 요구한다.
- 활용 목적·설명: `공개 데이터(국토교통부 물류창고업등록정보)의 인천 소재 창고 주소 수백 건을 좌표로 변환해 분포 분석에 쓴다. 서버 측 일괄 조회, 결과는 공개 저장소에 출처와 함께 기록한다.`

## 2. 브이월드 — 선택 (대조용)

**사이트**: 브이월드 `https://www.vworld.kr` → 회원가입 → 「오픈API」 → 「인증키」 → 「인증키 발급」.
- 체크할 API: **지오코더 API**(주소→좌표). 다른 것은 체크하지 않는다.
- 서비스 URL: `https://jisangj03-dev.github.io/incheon-port-analysis/`
- 활용 목적: `다른 원천에서 받은 좌표의 거리 검증(무작위 표본 10건 내외, 실시간 호출만, 결과 저장 안 함)`
- 가입 이메일로 온 승인 메일에서 승인해야 키가 활성화된다(검색 결과 기준).
- 넣을 변수: `VWORLD_KEY`

## 3. 넣을 곳 — 두 군데

**(가) Claude Code 클라우드 환경 변수** — 세션이 돌리려면 여기가 필요하다.
claude.ai/code 에서 세션 제목줄의 클라우드 환경 메뉴 → 환경 **편집(Edit)** → 환경 변수 칸에 한 줄씩:
```
JUSO_SEARCH_KEY=발급받은값
JUSO_COORD_KEY=발급받은값
VWORLD_KEY=발급받은값
```
**같은 화면에서 네트워크 접근도 열어야 한다** — 2026-09-30 이 환경은 아래 호스트를 전부 막았다(연결 거부 403).
허용 목록에 추가하거나 접근 수준을 넓힌다:
`business.juso.go.kr` · `api.vworld.kr` · `www.data.go.kr` (· 원본 파일 내려받기에 `file.data.go.kr` 가 쓰일 수 있다 [미확인]).
접근 수준 설명 = `https://code.claude.com/docs/en/claude-code-on-the-web`.

**(나) 노트북 `.env`** — 저장소 뿌리(`incheon-port-analysis\.env`)에 `.env.example` 을 복사해 값을 채운다.
```
copy .env.example .env
```
`.env` 는 `.gitignore` 에 있어 커밋되지 않는다. 확인: `git check-ignore .env` 가 `.env` 를 찍으면 된다.

## 4. 원본 파일 한 개 내려받기 (사람 손 · 1분)

`https://www.data.go.kr/data/15083282/fileData.do` → 「다운로드」 → CSV.
**파일 이름·수정일(기준일)을 그대로 두고** 저장소 밖에 둔다. 그다음:
```
python analysis/collect_warehouses.py --src <받은파일.csv> --basis <기준일 YYYY-MM-DD>
python analysis/geocode.py --in analysis/incheon_warehouses.csv --col 소재지 --dry-run
python analysis/geocode.py --in analysis/incheon_warehouses.csv --col 소재지
python analysis/geocode.py --in analysis/incheon_warehouses.csv --col 소재지 --sample 10
```
클라우드 네트워크가 열리면 이 단계도 세션이 할 수 있는지 먼저 친다 — 포털 내려받기가 로그인을 요구하면 사람 손이다.

## 5. 무료·결제·한도 — 공식 문서로 확인했나

**원문 페이지를 이 컨테이너에서 못 열었다**(`*.go.kr` 전부 차단 · WebFetch 도 같은 차단). 아래는 **검색 요약·제3자 문서 기준**이다.
**「공식 문서로 확인」 요구는 충족 못 했다 — 발급 화면에서 오너가 눈으로 확인할 칸을 같이 적는다.**

| | 무료 | 결제수단 | 일일 한도 | 확인 상태 |
|---|---|---|---|---|
| 도로명주소 검색API | 무료로 알려짐(공공데이터포털 해당 API 「비용부과 없음」 표기로 알려짐) | 요구 사례 못 찾음 | 명시 한도 못 찾음 | **[미확인]** — 신청 화면에 요금·결제 칸이 있는지 본다 |
| 도로명주소 좌표제공API | 같음 | 같음 | 같음 | **[미확인]** |
| 브이월드 지오코더 2.0 | 무료로 알려짐 | 요구 사례 못 찾음 | **일 40,000건**(레퍼런스 문구로 인용됨) | 한도·저장 금지 문구는 검색 요약 두 건 일치 · **원문 [미확인]** |

첫 배치는 수백 건이라 어느 한도에도 안 걸린다. **결제수단을 묻는 화면이 하나라도 나오면 거기서 멈추고 알려 달라.**
