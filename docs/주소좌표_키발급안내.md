> 키 셋 중 **꼭 필요한 것은 도로명주소 둘**이고 브이월드는 선택이다.

(`geocode.py --refine-only` → 좌표 키가 들어온 뒤 보통 실행).

## 왜 도로명주소가 주력이 됐나 (한 단락)

브이월드 지오코더 API 2.0 레퍼런스에 「API 요청은 실시간으로 사용하셔야 하며 **별도의 저장장치나 데이터베이스에 저장할 수 없습니다**」라는 문구가 있다.
좌표를 저장소에 캐시하는 이번 설계와 맞지 않는다. 그래서 **저장하는 좌표는 행정안전부 도로명주소 좌표제공 API**에서 받고,
브이월드는 무작위 표본의 **거리 대조에만 실시간으로** 쓴다(결과를 어디에도 안 쓴다). 경위 = `docs/주소좌표_판정기준_선커밋_20260930.md` 끝 절.

## 1. 도로명주소 — 필수, 승인키 두 개

**사이트**: 주소기반산업지원서비스 `https://business.juso.go.kr` → 상단 「API 신청」(또는 「API 신청하기」).
**한 번에 하나씩 두 번 신청한다** — 1 시스템 1 승인키라 API 종류가 다르면 키도 다르다.

| 신청 | API 종류 | API 유형 | 넣을 변수 |
|---|---|---|---|
| ① | **도로명주소** | **검색API** (팝업API 아님) | `JUSO_SEARCH_KEY` |
| ② | **좌표제공** | **검색API** (팝업API 아님) | `JUSO_COORD_KEY` |

**입력 칸 문구(그대로 붙여도 된다)**
- 시스템명: `측심 인천 물류시설 좌표 변환`
- 서비스 URL(또는 사이트 주소): `https://jisangj03-dev.github.io/incheon-port-analysis/`
- 서비스 용도: **개발** 으로 먼저 받는다(신청 즉시 발급). 운영 전환은 첫 배치가 기준을 넘은 뒤에 한다 — 운영 전환은 본인인증을 요구한다.
- 활용 목적·설명: `공개 데이터(국토교통부 물류창고업등록정보)의 인천 소재 창고 주소 수백 건을 좌표로 변환해 분포 분석에 쓴다. 서버 측 일괄 조회, 결과는 공개 저장소에 출처와 함께 기록한다.`

## 2. 브이월드 — 선택 (대조용)

**사이트**: 브이월드 `https://www.vworld.kr` → 회원가입 → 「오픈API」 → 「인증키」 → 「인증키 발급」.
- 체크할 API: **지오코더 API**(주소→좌표). 다른 것은 체크하지 않는다.
- 서비스 URL: `https://jisangj03-dev.github.io/incheon-port-analysis/`
- 활용 목적: `다른 원천에서 받은 좌표의 거리 검증(무작위 표본 10건 내외, 실시간 호출만, 결과 저장 안 함)`
- 가입 이메일로 온 승인 메일에서 승인해야 키가 활성화된다(검색 결과 기준).
- 넣을 변수: `VWORLD_KEY`

**(가) Claude Code 클라우드 환경** — 세션이 돌리려면 여기가 필요하다. 2026-09-30 오너가 실제로 누른 순서:

1. claude.ai/code 입력칸 위 **Default**(환경 이름) 를 누른다 → **클라우드** 탭.
2. **Default 줄의 톱니** — 마우스를 그 줄에 올려야 보인다.
3. **네트워크 액세스 → 「사용자 지정」**. 허용 도메인 칸에 **한 줄에 하나씩**:
   ```
   business.juso.go.kr
   api.vworld.kr
   www.data.go.kr
   www.nlic.go.kr
   ```
   **기본 목록 포함** 체크를 켠다(끄면 pypi·GitHub 등 기본 허용이 빠진다).
4. **환경 변수** 칸에 `KEY=값` 을 한 줄에 하나씩:
   ```
   JUSO_SEARCH_KEY=발급받은값
   JUSO_COORD_KEY=발급받은값
   ```

5. **변경사항 저장**.

## 4. 원본 파일 한 개 내려받기

**포털에는 파일이 없다 — 링크형이다.** `data.go.kr/data/15083282` 의 「바로가기」는
`/tcs/dss/selectLinkUrl.do?publicDataPk=15083282` 를 거쳐 **국가물류통합정보센터**
`http://www.nlic.go.kr/nlic/WhsStatsWarehouseLocation.action` 으로 보낸다(2026-09-30 실측 · 포털 제목 `국토교통부_물류창고업등록정보_20250701`).
그래서 **`www.data.go.kr` 만 열어서는 못 받는다 — `www.nlic.go.kr` 가 필요하다.** 거기서 파일 내려받기가 로그인을 요구하는지는 **[미확인]**(못 열었다).

**2026-09-30 21시 재측(`www.nlic.go.kr` 허용 뒤)** — HTTPS 만 된다(HTTP 는 연결 끊김) · 연결이 간헐적으로 끊긴다.
- 위 통계 화면의 「엑셀다운로드」는 **시도 × 근거법 집계표**다(주소 없음). 받아서 `collect_warehouses.py --stats` 로 정리했다 → `analysis/warehouse_stats_by_sido.csv`.
- **주소가 든 목록**은 같은 사이트 「물류시설 → 물류창고업 현황」(`https://www.nlic.go.kr/nlic/WhsInfoWarehouseSch.action`)의 「엑셀다운로드」다.
  화면에는 로그인 요구가 없다(창고종류를 하나 이상 체크해야 버튼이 돈다). **세션의 내려받기 요청은 자동 모드 분류기가 막았다 — 우회하지 않았다.**
  사람 손: 그 화면에서 창고종류 전부 체크 → 「엑셀다운로드」 → 받은 파일을 CSV 로 저장해 아래 `--src` 로 준다.

사람 손으로 받을 때: 위 nlic 주소에서 내려받는다(화면 구성은 **[미확인]** — 이 컨테이너에서 못 열었다). 받은 파일은 이름·기준일을 그대로 둔다.
**파일 이름·수정일(기준일)을 그대로 두고** 저장소 밖에 둔다. 그다음:
```
python analysis/collect_warehouses.py --src <받은파일.csv> --basis <기준일 YYYY-MM-DD>
python analysis/geocode.py --in analysis/incheon_warehouses.csv --col 소재지 --dry-run
python analysis/geocode.py --in analysis/incheon_warehouses.csv --col 소재지 --refine-only   # 좌표 키 전
python analysis/geocode.py --in analysis/incheon_warehouses.csv --col 소재지
python analysis/geocode.py --in analysis/incheon_warehouses.csv --col 소재지 --sample 10
```
좌표 키가 아직 없으면 둘째 줄 대신 `--refine-only` 로 정제만 한다. 클라우드 네트워크에 `www.nlic.go.kr` 가 열리면 이 단계도 세션이 할 수 있는지 먼저 친다 — 로그인을 요구하면 사람 손이다.

## 6. 2026-10-03 갱신 — 좌표까지 남은 것 하나와 가장 짧은 길

**지금**: 정제는 끝났다(10/3 재실행 444/454 = 97.8% · 9/30 값과 같다). 좌표만 0건이다. 이 세션 환경에 `JUSO_COORD_KEY` 가 없다.

**10/7 검색 키 만료는 막힘이 아니다.** 정제 캐시(`analysis/geocode_cache.csv` — 원주소·정제 주소·건물 식별자 · 상호 없음)는 공개 저장소에 안 올리고
조타(비공개) `inbox/측심_geocode_cache_20261003.csv` 에 둔다. 좌표 단계는 그 파일을 `analysis/geocode_cache.csv` 로 되돌려 놓고 돌리면 검색 API 를 다시 안 부른다.

**가장 짧은 길 — 좌표제공 「개발」 키(운영 심사를 기다리지 않는다)** · 운영자 손 · 약 5분
1. `https://business.juso.go.kr` 로그인 → 「API 신청」 → API 종류 **좌표제공** · 유형 **검색API** · 서비스 용도 **개발**(위 1절 문구 그대로).
   공공데이터포털 15056663 의 설명이 「신청 즉시 이용 가능」을 든다 — 9/30 검색 키도 개발 용도는 바로 나왔다.
2. 클라우드 환경 → 환경 변수에 `JUSO_COORD_KEY=<값>` 한 줄 → 저장 → **새 세션**.
3. 새 세션이 할 일(세션 몫): 캐시 되돌리기 → `geocode.py --in analysis/incheon_warehouses.csv --col 소재지` → `--summary` → `--sample 10`(시드 20260930) → 채팅 대조 10건.
- 개발 키는 7일짜리다. 첫 배치(444건)는 하루에 끝난다. 운영 키 심사는 그대로 두고, 나오면 갈아 끼운다.

**키 없이 가는 길(대안 · [미확인])**: 같은 사이트 「주소정보 다운로드」의 **위치정보요약DB**(시도별 건물 좌표 파일)를 인천만 받아 `inbox/` 에 넣으면,
세션이 건물 식별자로 오프라인 대조한다. 다운로드 화면이 장바구니형이라(10/3 화면 코드 확인) **로그인이 필요해 보인다** — 그 경우 운영자 손이다. 개발 키 길이 막힐 때만 쓴다.
