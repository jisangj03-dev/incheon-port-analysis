## 2. ruflo — 왜 떨어졌나

**G2 가 실행 시점에 풀린다.** `node_modules` 에는 `3.39.2` 로 고정해 깔았는데,
`ruflo init` 이 써 놓는 `.mcp.json` 은 **`npx -y ruflo@latest mcp start`** 를 부른다.
**고정한 것과 도는 것이 다르다.** 선커밋 G2 는 「같은 명령이 같은 것을 다시 깐다」였고 이건 아니다.

**G3 이 없다.** `ruflo uninstall` 이 없다. 그리고 지운 뒤에 실제로 남는 것을 쟀다 —

```
연습 폴더 둘 rm -rf   →  흔적 0
~/.claude/CLAUDE.md   →  **남아 있다** (322 B)
~/.claude-flow/update-state.json → 남아 있다 (114 B)
```

**도구를 지웠는데 지시문이 남았다.** 이것이 G3 의 답이다. 경위는 사고 112.

**덮는가는 따로 쟀고 — 안 덮는다.** 표적 `CLAUDE.md` 를 심고 다시 친 결과 **한 바이트도 안 건드렸다.**
`settings.json` 은 **훅을 안 넣었고**(기존 파일이 있으면 훅 병합을 건너뛴다) `permissions.allow` 4 · `env` 3 만
**사본 없이** 덧붙였다. *운영자가 걱정한 자리는 안전했고, 안 본 자리가 걸렸다.*

**게이트를 떠나서 문면이 우리와 정면으로 어긋나는 것도 둘 있었다**(§6 표).

## 3. 옴니루트 — 통과했으나 문이 사람 손

다섯을 다 통과한다. 연습 폴더에서 `--version`(3.8.50)·`--help` 가 돌고, **지시문 자리를 안 건드린다**(63 → 63).

**그 이상은 안 갔다. 세 가지가 사람 손이다.**

1. **자격 증명.** `--api-key`(`OMNIROUTE_API_KEY`)가 있어야 라우팅이 성립한다. 위임 경계 그대로 안 만졌다.
2. **설치 스크립트 10개가 막혀 있다.** npm 이 `keytar`(OS 자격 증명 저장소)·`koffi`·`onnxruntime-node`·
   `sharp`·`tls-client-node`·`@swc/core`·`esbuild` 등과 **옴니루트 자신의 postinstall** 을 안 돌렸다.
   서버를 세우려면 `npm approve-scripts` 로 열어야 한다 — **네이티브 빌드 10건을 승인하는 일이라 안 했다.**
3. **BASE_URL.** 운영자 경계가 「인천·측심 세션의 BASE_URL 을 상시로 바꾸지 마라」다. 안 바꿨다.

**배포본이 `.env`(170 KB)를 들고 온다.** `.env.example`(170 KB)과 190 B 차이로 사실상 같은 파일이고,
`BASE_URL=http://localhost:20128` — **클라우드가 아니라 자기 기계에 세우는 게이트웨이**다.
다만 `JWT_SECRET`(128자)·`API_KEY_SECRET`(64자)이 **패키지에 실려 온다** — 모든 설치가 같은 값을 쓴다.
`REQUIRE_API_KEY` 를 끌 수 있으므로, **세우게 되면 그 둘을 먼저 바꾸는 것이 첫 일이다.**
*값은 여기 안 적는다(§4.1). 키 이름과 길이만 적었다.*

## 4. claude-mem — 겹침에 대한 답

**질문은 「대체할 것인가 겹쳐 둘 것인가」였다. 답은 셋 다 아니다 — 두 체계가 「기억」을 다르게 정의한다.**

| | claude-mem | 우리 넷 |
|---|---|---|
| 무엇을 남기나 | 모델이 대화록을 **요약·압축**한 것 | STATUS(지금 참인 상태) · 작업기록(경위) · 사고기록(터진 일) · 부트블록 |
| 어디 사나 | 로컬 저장소 + 워커 서비스 | **저장소 안 파일** |
| 어떻게 도로 오나 | 세션 시작에 **주입** | 세션이 **읽는다**(CLAUDE.md 4단계) |
| 바뀐 걸 어떻게 아나 | — | **`git diff`** |

**우리 방법의 뿌리가 「기억이 아니라 파일을 읽는다」이고, 사고 96 의 교훈이
「변화가 `git diff` 로 남아야 세션이 아니라 이력이 기억한다」다.** claude-mem 의 저장소는 그 축에 안 얹힌다.
그리고 STATUS 에 **「요약 금지 · 전문 덤프」**를 박아 둔 이유가 사고 31 —
**요약이 원본을 대신하면 이틀 만에 낡는다.** 자동 요약 기억은 그 실패를 체계로 만든 것이다.

**설치 실측에서 나온 것 둘.**
- `claude-mem install` 이 쓰는 자리는 **`~/.claude/settings.json` · `~/.claude-mem/settings.json` ·
  `~/.claude/plugins/marketplaces/thedotmack/…`** — 소스에서 확인했다. **전역이다.**
  운영자는 인천·측심 말고 다른 용도로도 이 기계에서 클로드 코드를 쓴다(`docs/전역과_저장소.md`).
- **원격 측정이 기본 켜짐**이다(`telemetry … on by default, opt-out` · 자기 도움말). 대화록을 읽는 도구다.
  사고 101 이 **「토큰이 대화록에」**였다.

**그래서 `install` 을 안 쳤다.** CLI 는 깔려 있고 판정 근거는 위와 같다.
**뒤집으려면 기존 넷을 걷어야 하고, 그건 도구 도입이 아니라 체계 교체다** — 운영자 결정 자리다.
