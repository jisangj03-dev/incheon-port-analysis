## 성공 기준 (전부 통과해야 개편 완료)
1. **정문 하나**: 머지만으로(노트북 없이) 공개된다. 다른 주소는 정문으로 안내만 한다.
2. **도구까지 1클릭**: 홈 첫 화면(스크롤 0)에서 셀러 도구로 가는 길이 보이고, 상단 메뉴에 도구가 있다.
3. **계산기 첫 답 5칸 이하**: 필수 입력 5칸 이하로 첫 결과(건당 총비용)가 나온다. 정밀 10항목은 펼침으로.
4. **결과가 입력과 같은 화면**: 모바일 포함, 입력하는 동안 건당 총비용이 화면 안에 보인다.
5. **세 견적 동시 비교 + 손익분기**: 지금 방식·견적 A·B를 한 화면에서 비교하고, "월 몇 건부터 어느 쪽이 싼가"를 그래프로 보여 준다.
6. **계산 정확도 회귀 0**: 엑셀 가상 샘플과 같은 답(4,044 / 2,805 / 2,960원)이 자동 테스트로 고정된다. 다르면 머지 금지.
7. **'모름' 경고 유지·강화**: 견적서에 없는 칸은 숨은 비용 경고로 결과 옆에 뜬다.
8. **공유**: 입력값이 주소에 담겨 링크로 공유된다(서버 저장 없음).
9. **검색 기본**: sitemap.xml·robots.txt 200, 공개 페이지 description·OG 누락 0, 블로그 /79 ↔ 계산기 상호 링크.

11. **확장 1축**: 범위 문서 순서대로 항공화물 축의 판정 기준 선커밋 PR 1개(데이터 수집은 그다음).
