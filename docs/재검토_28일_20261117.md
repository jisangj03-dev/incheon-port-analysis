## `?s=` 가 지금 재는 것 — 10/22 실측

기준 29 는 「계산기 사용」을 **공유 링크(`?s=`) 진입**으로 대신 잰다고 적었다. 그 기준이 설 때 `?s=` 를 만들던 것은 `astro/src/lib/calc-ui.ts`(3PL 물류비 계산기)·`sim-ui.ts`(시뮬레이터)였다.
**10/22 에 저장소를 다시 봤더니 지금 공개 지면 중 그 둘을 부르는 곳이 0 이다** — `/tools/logistics-cost.html`·`/tools/simulate.html` 둘 다 10/20 에 내려 도구 목록으로 돌려보낸다(`astro/src/pages/tools/` 의 `Redirect`).
지금 도구 다섯은 상태를 주소에 싣지 않는다. 주소에 상태를 싣는 공개 지면은 맥주 게임(`/sim/beer-game.html?o=…`) 하나다.

그러므로 11/17 의 2-g 는 **「계산기 사용」의 대리값이 아니다** — 내린 지면을 가리키는 옛 공유 링크가 남아 있으면 그것이 잡힐 뿐이다. 그날 적을 문장은 이것이다:
**「Cloudflare 는 사용자 정의 이벤트가 없어 도구 직접 사용 횟수는 재지 못한다. 기준 29 의 대리값(`?s=`)은 지금 지면이 만들지 않는다. 남는 것은 도구 지면 경로별 조회(2-a~2-e)뿐이다.」**
기준 자체는 선커밋이라 고치지 않는다. 맥주 게임 `?o=` 진입을 대신 셀지는 그날의 판단이고, 세면 「기준 29 밖의 참고값」이라고 적는다.
