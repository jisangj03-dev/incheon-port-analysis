- **묶음** — 공고명 넣는 말로 「운송·배송 / 보관·창고 / 통관·무역 / 항만·해운·항공」 넷.
- **표기** — 지면은 다른 도구처럼 `aiMark()`. 다만 **주마다 바뀌는 공고 목록 자체는 사람이 검수하지 않는다** — 목록 위에 「자동 수집 · 위 규칙 그대로 · 검수 안 함」을 적는다(정체성 §2-4: 검수한 것에만 검수 표기).
- **폐기** — 21일 창에서 넣는 말에 걸리는 공고가 5건 미만이면 싣지 않는다. 빼는 말 규칙이 틀려 엉뚱한 공고가 섞인 것을 발견하면 규칙을 고치고 이 절에 「바꿈」을 적는다.
