## ④-상세 — B6 · B7 · B10(작업 **전** 선커밋 · 2026-10-15)

- **있는 것** — 보고서에는 B6(og/<id>.jpg)·B7(/embed/<id>.html)이 이미 있다. 이번 일은 **도구 일곱**(맥박·등시선·트리맵·수입원가·초크포인트·묘박지·입찰 레이더)으로 넓히고 B10 을 새로 만든다.
- **B6 도구 카드** — 도구마다 1200×630 `og/tool-<id>.jpg` · 도구 지면 `og:image` 가 그것을 가리킨다. 카드의 큰 숫자와 질문은 **찍는 순간 그 도구 지면에서 읽는다**(카드가 숫자를 따로 계산하지 않는다 → 지면 숫자와 갈라질 수 없다). 읽은 값은 `og/cards.json` 에 남기고, 시험이 지면 숫자와 대조한다. 하나라도 못 찍으면 종료 1(깨진 카드 배포 0).
- **B7 도구 퍼가기** — `/embed/tool-<id>.html`: 카드 그림 · 질문 · 기준일 · 출처 · CSV · 원 도구 링크. 분석 비콘 0 · 외부 요청 0 · noindex. 도구 지면 신뢰 꼬리에 「퍼가기」 → iframe 코드. CSV 는 도구마다 이미 있다(바꾸지 않는다).
- **B10 콘텐츠 큐** — `tools-build/content_queue.py` 가 도구별 LinkedIn·블로그·Threads 초안을 `content-queue/<날짜>/<id>.md` 로 만든다. 숫자는 **파생 데이터 파일에서만** 가져오고, 시험이 초안 속 숫자 ⊂ 데이터 파일을 본다(밖의 숫자가 있으면 그 초안은 버린다 — 생성기가 쓰지 않는다). data-v3 예약 갱신이 PR 을 열 때 같이 돈다. **게시 0** — 초안 머리에 「게시 = 선장님」.
- **폐기** — 카드 캡처가 CI 시간을 3분 넘게 늘리면 도구 카드를 정적 틀(질문만)로 줄인다. 초안 생성이 데이터 밖 숫자를 피할 수 없으면 그 채널 초안은 만들지 않는다.

## ⑤-상세 — 도구 시연 영상 3편(작업 **전** 선커밋 · 2026-10-15)

- **세 편** — ① 초크포인트 충격(길목 고르기 → 통항 선 · 교역 몫) ② 환율 파도·수입원가(주 바꾸기 → 원가 · 운임 파도) ③ 공공입찰 레이더(묶음 고르기 → 목록). 편마다 9:16(1080×1920 · 릴스) · 1:1(1080×1080 · LinkedIn) 두 판 · 길이 30초 안.
- **만드는 법** — Actions 에서 사이트를 빌드하고 Playwright 가 도구 지면을 조작하며 녹화(webm) → Remotion(4.0.530 고정 · `video/`)이 머리 자막(질문) · 녹화 · 숫자 자막 · 출처·기준일 · 끝 카드(주소)로 합성 → mp4. 결과는 Actions 산출물 + 콘텐츠 큐 목록(`content-queue/video/README.md`). **게시 = 선장님.**
- **화면 숫자 = 데이터 파일** — 자막 숫자는 `og/cards.json`(지면에서 읽은 값)과 data/derived 에서만. 렌더 전에 자막 묶음(props)을 같은 숫자 검사(check-data-numbers)로 걸러 밖의 숫자가 있으면 그 편을 렌더하지 않는다.
- **자막에 출처·기준일** — 편마다 끝까지 아래 띠에 「출처 · ○ 기준」.
- **돈 0** — Remotion 은 개인·소규모(3인 이하) 무료 라이선스 범위. 유료 렌더(Lambda 등) 안 쓴다. Actions 무료 시간 안.
- **폐기(축소)** — Remotion 렌더가 Actions 30분을 넘기거나 유료를 요구하면 그 편은 녹화 GIF + 정지 카드(B6)로 줄인다.
