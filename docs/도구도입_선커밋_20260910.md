# 도구 도입 — 선커밋 판정 기준 (2026-09-10)

> **이 문서는 실물을 보기 전에 쓴다.** 배포처를 열어 보고 기준을 쓰면 기준이 실물에 맞춰지고,
> 그러면 「무엇이 되면 성공인가」가 아니라 「이것이 왜 괜찮은가」가 된다(§3-7).
> **커밋 뒤 한 글자도 고치지 않는다.** blob 해시를 아래 「이행」 절에 적는다.
>
> 판정은 설치 뒤에 이 기준 **그대로** 한다. **FAIL 이면 지운다** — 남겨 두고 나중에 보지 않는다.
> 우리가 데이터에 하는 것을 도구에도 한다.

## 0. 대상 — 위임이 준 목록 그대로

prompt master · 포니테일 · 그래피파이 · 옴니루트 · 에이전트 스킬즈 · claude-mem ·
find-skills · vibesec · playwright cli · supabase mcp · strix · skillui · context7 · ruflo

여기에 위임의 「참고」가 배포처까지 준 둘을 더한다 — **watermarks-remover** · **Agent-Reach**.

## 1. 공통 기준 — 다섯 (하나라도 미달이면 설치하지 않거나 지운다)

| | 기준 | 어떻게 판정하나 |
|---|---|---|
| **G1 실물 특정** | 공식 배포처가 **하나로** 정해진다. 이름이 같은 다른 패키지와 갈린다 | 저장소/레지스트리 주소 · 소유자 · 라이선스를 적을 수 있는가. **못 적으면 FAIL** |
| **G2 버전 고정** | **특정 버전·태그·커밋**으로 깔린다 | 설치 명령에 버전이 박혀 있고, 같은 명령이 같은 것을 다시 깐다. **기본 브랜치 tarball 은 G2 미달** |
| **G3 되돌리기** | 제거 명령이 있고 **실제로 돌아간다** | 깔고 → 지우고 → 흔적 0 을 확인 |
| **G4 발화** | 설치 뒤 그 도구가 **실제로 무언가를 한다** | 한 줄 명령이 0 아닌 산출을 낸다. **「설치됐다」는 발화가 아니다**(사고 26) |
| **G5 경계** | 자격 증명·세션 권한·훅·자동 실행·개시 검사를 **안 건드린다** | 건드리면 **설치 전 보고하고 멈춘다**. 위임 경계 3항 |

**G1 이 이 라운드의 주된 게이트다.** 위임이 「이름이 같은 다른 패키지가 있는 생태계」라고 적었고,
**이름만으로 깐 것이 우리가 아는 그것이라는 보장은 없다.**

## 2. 항목별 기준 — 「무엇이 되면 성공인가」 한 줄씩

이름이 기능을 말하는 것은 그 기능으로, 아닌 것은 **G1 통과 자체**를 기준으로 삼는다.

| 항목 | 성공 기준 (한 줄) |
|---|---|
| **watermarks-remover** | `inspect_text.py` 가 **안 보이는 문자를 심은 표본에서 그것을 찾아내고**, `clean_text.py` 가 지운 뒤 다시 검사하면 0 이 된다 |
| **Agent-Reach** | `agent-reach doctor` 가 채널 상태를 내고, **자격 증명 없이 열리는 채널(유튜브·깃허브·RSS·웹)과 필요한 채널을 갈라 보여 준다** |
| **context7** | 라이브러리 문서를 한 건 실제로 가져온다 — **질의에 대해 0 아닌 문서 조각**이 온다 |
| **playwright cli** | **이미 있는 것과 겹치지 않는 새 능력**을 준다. 못 대면 설치하지 않는다(측심 `tools/node_modules` 에 이미 있고 Playwright MCP 도 있다) |
| **supabase mcp** | **토큰 없이 성립하지 않으면 설치하지 않는다.** 자격 증명은 안 만진다 — 운영자가 칠 명령만 낸다 |
| **strix** | 설치 뒤 **우리 자산 하나를 실제로 점검**해 산출을 낸다(점검까지만 · 위임 경계 6항) |
| **vibesec** | 위와 같다 |
| **claude-mem** | **G5 를 먼저 통과해야 한다** — 훅·자동 실행을 붙이면 설치 전 보고. 그리고 **STATUS·사고기록·부트블록과 같은 자리를 노리므로**, 「이것이 그 셋을 대체하는가, 겹치는가」에 답할 수 있어야 한다 |
| **에이전트 스킬즈 / find-skills / skillui** | G1 통과 + **스킬 하나가 실제로 목록에 뜨고 불러진다** |
| **prompt master** | G1 통과 + 한 줄 명령이 0 아닌 산출 |
| **포니테일 · 그래피파이 · 옴니루트 · ruflo** | **G1 통과가 곧 기준이다.** 배포처가 하나로 안 정해지면 **설치하지 않고 보고**(위임 경계 1항) |

## 3. 이 라운드가 미리 정해 두는 처분

- **G1 미달 → 설치 안 함.** 「비슷한 이름의 패키지를 대신 깔아 본다」를 하지 않는다.
  위임이 그것을 이름으로 금지했다.
- **G5 저촉 → 설치 전 보고하고 멈춘다.** 훅·개시 검사·세션 권한을 건드리는 것은
  이 저장소가 여섯 라운드 걸쳐 세운 자리다. 도구가 그 위에 덧쓰게 두지 않는다.
- **설치 위치는 저장소 밖.** 프로젝트 저장소 안에 남의 저장소를 복제하지 않는다(위임 경계 5항).
  전역 도구는 전역에, 스킬은 스킬 자리에, 검사용 임시물은 스크래치패드에.
- **ZIP 까지만 만드는 것**(클로드 앱 스킬)은 업로드를 하지 않는다. 경로만 낸다.
- **표식 지우기 도구는 설치까지.** 측심·인천 산출물에는 **돌리지 않는다** —
  그쪽은 AI 를 썼다고 이미 밝혀 둔 축이고, 표식을 지우는 것은 §2.2 가 지키는 것과 반대 방향이다.

## 4. 판정 표에 반드시 적을 것

항목마다 **실물 주소 · 버전 · 설치 여부 · 성공 기준 · PASS/FAIL · 제거 명령.**
**「모름」은 PASS 가 아니다**(사고 26). 확인 못 한 것은 [미확인]으로 적고 설치하지 않는다.

## 5. 이행

- **blob 해시를 이 파일 안에 적지 않는다** — 파일 자신의 해시를 파일이 들면 순환이고,
  적는 순간 해시가 바뀐다. 해시는 **커밋 메시지**와 **판정결과 문서**가 든다.
  확인 = `git hash-object docs/도구도입_선커밋_20260910.md`.
- 이 파일은 커밋 뒤 **한 글자도 고치지 않는다.** 고치면 해시가 갈리고 선커밋이 아니게 된다.
- 판정 결과는 **별도 문서**(`docs/도구도입_판정결과_20260910.md`)가 든다. 이 파일에 결과를 적지 않는다.
