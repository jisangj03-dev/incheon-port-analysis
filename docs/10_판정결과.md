## 6. 노출 이력 · 한계

- **선커밋은 월별 값을 계산하기 전에 커밋됐다.** 다만 **#09 보다 약한 선커밋**이다 —
  #09 는 API 를 부르기 전이었고 이 편은 **원시 CSV 가 이미 저장소에 있었다.**
  선커밋 문서 §0-1 이 무엇이 이미 노출됐는지 표로 든다. **약하다는 것을 약하다고 적는다.**
- **하한 두 개는 판정 구간이 아니라 근거 구간(2022~2025)에서 나왔고 먼저 커밋됐다**
  (`analysis/basis_10_monthly_floor.py` · 커밋 `b34a258`). 그 스크립트는 판정 구간을
  **열지 않으며** 인수시험이 행동과 소스 두 겹으로 그것을 강제한다.
- **W4 문면을 한 번 고쳤다**(`3442dfa`). 최초 문안 「마지막 출현월 이후 재출현이 없다」가
  **동어반복**이라 아무것도 판정하지 않았다. **월별 값 계산 이전**이고 git 이력이 그것을 든다.
  선커밋 문서 「노출 이력」 표에 적혀 있다.
- **[미확인] 2005~2017 소급 적재의 원자료와 방법.** #09 §2 — 적재일이 `2018-06-27` 하나다.
  **그러므로 2005~2017 값의 지위는 「관측」이고 「확정」으로 부르지 않는다.**
- **[미확인] 이 API 가 과거분을 수정하는지.** 적재일이 하나뿐이라 흔적이 없고,
  **흔적이 없는 것과 수정이 없었던 것은 다르다.**
- **우리 시리즈 전체가 외항(`ocCt=1`)만 본다.** §4-1 이 실측한 대로 이 구간의 연안에는
  **114,580.2 TEU** 가 있었다. 같은 구간 외항 합 **9,414,765.8 TEU** 의 **1.217%** — 작지만 **0 이 아니다.**
  **「인천항 공컨」이라고 쓸 때 그것이 외항만이라는 것을 지면이 들어야 한다.**
- **인과·목적 서술 없음.** 미성립 달이 2005~2013 에 몰려 있는 것은 값이고,
  **왜인지는 이 데이터가 답하지 않는다.**
- **이 판정은 규격 축을 안 본다.** 그것이 이 편이 열린 이유이자 이 편의 한계다 —
  규격 내역이 어긋난 10개 연도의 **규격 축 문제는 그대로 남아 있다**(#09 §3).
