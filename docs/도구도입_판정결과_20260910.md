## 지운 것 — Agent-Reach 와 그 이유

**`agent-reach doctor` 가 세션에 스킬을 설치했다.** 「doctor」는 상태를 보는 명령으로 읽히는데,
실행 끝에 이렇게 찍었다:

```
Skill installed for Agent: C:\Users\user/.agents/skills\agent-reach
Skill installed for Claude Code: C:\Users\user/.claude/skills\agent-reach
```

**지우고 다시 쳐 봤더니 또 깔렸다.** 즉 이 도구는 **자기 상태를 보는 것만으로 세션 능력이 늘어난다** —
선커밋 G5(「세션 권한·훅·자동 실행을 안 건드린다」)를 **피할 방법이 없다.**

기능 자체는 기준을 채웠다 — 13채널 중 4개가 자격 증명 없이 가용, 나머지는 무엇이 필요한지 갈라 냈다.
**그래도 지웠다.** 위임이 「못 미치면 FAIL 로 적고 지워라 — 남겨 두고 나중에 보자고 하지 마라」고 했고,
**기능이 좋다는 이유로 경계를 무르면 경계가 아니다.**

제거 확인: `.claude/skills` 0건 · `.agents/skills` 0건 · `~/.claude/settings.json` 0건 · venv 삭제.
