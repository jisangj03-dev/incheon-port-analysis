> 선장님 질문(10/21 21:00): 「지면마다 최신화해야 할 숫자가 많은데 어떻게 할 건가, 아니면 개편할 건가」.
> 답: **공개 13지면의 숫자 326개 가운데 사람 손이 필요한 것은 26개(8%)이고, 전부 배송 등시선 한 계열이다.** 이것을 월 1회 자동 갱신에 넣어 ③을 0으로 만든다. 첫 화면은 과제 1에서 개편하고, 새 첫 화면 숫자도 전부 ①로 만든다. 나머지 지면은 유지한다.

## 어떻게 셌나 — 흔들어 보기(실측)

숫자가 「어느 파일에 들어 있나」로는 가를 수 없다. 원자료가 커서 거의 모든 숫자가 어딘가에 들어 있기 때문이다. 그래서 파일 묶음마다 값을 일부러 흔든 사본(자리마다 1.13~1.49배)으로 다시 빌드하고, 공개 지면 본문에서 **실제로 바뀐 숫자**를 그 묶음의 것으로 셌다. 어느 묶음을 흔들어도 그대로인 숫자(132개)는 하나씩 문맥을 보고 갈랐다. 장치 = `tools-build/number_inventory.py`.

- **① 자동** — 원천 → 데이터 파일 → 빌드. refresh 워크플로가 매일 다시 받는다(관세청 · 해양수산부 · 인천해수청 · 인천공항공사 · KCCI · PortWatch). 빌드가 데이터에서 다시 세는 값(축 눈금 · 개수 · 기준월)도 여기에 든다.
- **② 기록·정의** — 갱신하지 않는 게 맞고, 그렇게 표시된 숫자. 날짜·기간을 박은 기록(선박 밀도 2015~21 · 노트 날짜)과, 정의·방법 상수(맥주 게임 Sterman 설정 · 「1·2·3시간」 · 「1만 달러 예시」 · 「최근 12달」 · 「28일 평균」 · 지도 축척) · 식별자(API 번호 · CC BY 4.0 · 논문 쪽수).
- **③ 사람 손** — 사람이 워크플로를 손으로 돌려야 바뀌는 파일에서 온 숫자.

## ③을 0으로 — 방안

1. **배송 등시선(③ 26 · 지도 색 칸)** → **자동화.** refresh 에 월 1회(매달 첫 월요일) 단계를 둔다.
   - Geofabrik OSM 대한민국 추출 → `osm_iso.py`(이미 Actions 에서 돈다)
   - 카카오 내비 대조 → `navi_check.py`(시크릿 `KAKAO_REST_KEY` 있음 · 무료 쿼터 안 · 원 응답 저장 0)
   - 시간대 배율 → `reach_slots.py`
   - 신선도 원천 둘(OSM 도로망 · 카카오 대조)을 원천표에 더하고, 지면 출처 줄에 「원천 확인 · 다음 갱신 예정」을 단다.
   - 도로망은 달마다 크게 바뀌지 않는다. 다만 「갱신일이 박힌 계산」을 사람 손 없이 다시 돌리는 것이 원칙에 맞다.
   - 자동화가 실패하면 대신 「도로망 YYYY-MM 기준」을 박은 ②로 낮춘다.
2. **물류창고 개소(지도 원)** → refresh 에 분기 1회 단계(공공데이터포털 15083282 · 지금 키로 받는다).
3. **관세율표(HS → 세율)** → refresh 에 월 1회 확인(공공데이터포털 15051179 · 개정은 보통 연초) — 새 판이 있을 때만 바뀐다.
4. 시험 — `tests/freshness.spec.mjs` 에 새 원천 셋을 더한다. 확인이 기준 일수를 넘으면 빨강이다(월 단위 원천은 40일).

이렇게 하면 공개 지면 숫자는 ①과 ②만 남는다. ②는 모두 화면에 기간·출처·「설정」이 적혀 있다.

## 과제 1(첫 화면)과 같은 원칙 — 유통 축 원천에 필요한 것 하나

- 수도권 단위의 월간 유통·소비 통계(시도별 대형소매점 판매액 · 온라인쇼핑 동향 등)는 **KOSIS(통계청) OpenAPI** 에만 있다.
  - 공공데이터포털에는 시도별 월간 판매액 API 가 없다.
  - 온라인쇼핑동향 파일은 1회성이다(15113198).
- KOSIS 인증키는 무료이고, 회원가입 후 활용신청하면 자동 승인된다. **다만 가입·키 발급은 선장님 손이다**(자격 증명).
- 키를 저장소 시크릿 `KOSIS_KEY` 로 넣으면, 유통 축도 refresh 가 매달 받는 ①이 된다.
- 키가 오기 전까지는 무역 축을 수도권(서울·경기·인천)으로 넓힌다. 관세청 시도별 품목별 수출입(15101641)은 지금 키로 받는다. 시군구별 품목별 수출입(15134343)은 공공데이터포털에서 API 마다 하는 활용신청이 이 키에 되어 있는지 [미확인]이다 — 첫 실행으로 확인한다.
