# 신청서 초안 — 국가교통정보센터(ITS) 오픈 API 인증키(2026-10-15 · 선장님 손)

> 이 문서는 **초안**이다. 신청(회원가입·키 발급)은 선장님이 한다 — 자격 증명은 세션이 다루지 않는다.
> 키를 받으면 GitHub Actions 비밀 **`ITS_API_KEY`** 로 넣는다(값을 저장소·채팅·로그에 적지 않는다).

## 왜 필요한가
측심 「수도권 배송 등시선」은 지금 도로 등급별 **자유 흐름 가정 속도**로 도착 분을 계산한다. 카카오 내비(미래 출발시각)와 견준 결과
우리 값이 출근 08시 중앙값 −43.6%, 낮 14시 −27.4% 로 짧다(navi_check.json · 2026-10-15). 시간대별 **실측 소통 속도**(링크별 평균 속도)로
도로 속도를 바꾸면 이 차이를 줄일 수 있다.

## 신청 내용(붙여 넣을 문구)
- 이용 목적: 비영리 공공데이터 분석 사이트(측심)의 수도권 배송 도달권(등시선) 계산 — 시간대별 링크 평균 속도를 월 1회 빌드 때만 받아 도로 등급별·시간대별 평균 속도로 집계해 쓴다. 원 자료(링크별 실시간 값)는 재배포하지 않고 집계값만 게시한다.
- 사용 API: 교통소통정보(링크별 속도) · 표준노드링크(링크 ID ↔ 도로 등급 대응)
- 호출 빈도: 월 1회 · 수도권 범위 · 한 번에 수백 건 안(코드 상한을 둔다)
- 호출 위치: GitHub Actions(빌드 서버) — 사용자 브라우저에서 부르지 않는다(사이트 외부 요청 0 유지)

## 신청 전에 확인할 것(선장님)
1. 이용약관의 **재배포·2차 가공 게시** 조항 — 집계값 게시가 허용되는지. 막히면 세션은 통계(중앙값)만 쓰고 원 자료는 저장하지 않는다.
2. 무료 여부 · 호출 한도 · 결제수단 요구 — **Max 밖 지출이 생길 여지가 있으면 신청하지 않는다.**
3. 키 발급 뒤: Actions 비밀 `ITS_API_KEY` 등록 → 세션에 「등록됨」만 알린다.

## 키가 없는 동안
등시선 「시간대」 단추는 **카카오 내비 대조 중앙값으로 보정한 배율**(실측 소통 속도 아님 · 표본 30쌍)을 쓰고, 지면에 그렇게 적는다.
