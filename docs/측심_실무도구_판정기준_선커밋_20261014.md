## 2. 도구마다 지키는 꼴(완료 기준)

각 도구는 아래를 **전부** 넘어야 공개 전환 PR 에 들어간다. 못 넘으면 PR 설명에 못 넘은 칸을 적는다.

1. **실무 질문 한 줄**이 첫 화면 맨 위에 있다.
2. **3초 답** — 첫 화면에 움직이는 그림 하나와 숫자 하나. 1440·390 둘 다 첫 화면 안.
3. **조작** — 필터·선택·입력 중 하나 이상(관문·항만·창고·품목·연도·운임·환율).
4. **원문·CSV·갱신일** — 신뢰 꼬리(출처 대장 한 줄 · 「○일 기준」 · CSV 내려받기).
5. **연락** — 지면 끝 「이 분석을 우리 회사 숫자로」(AskTail).
6. **참고용·자문 아님** — 관세·원산지·세무·원가 계산은 지면 **안**에 「참고용 · 법률·세무·관세 자문 아님」.
7. **가짜 실시간 0** — 움직임은 기록된 날짜의 자료를 다시 재생한 것이고, 그 날짜를 같은 화면에 적는다.
8. **자동 갱신** — Actions 워크플로가 원천을 받아 파생 파일을 만들고 PR 로 올린다(월 · 일별 원천은 주 1회 이상). 세션 손이 없어도 돈다.
9. **출고 검사** — 외부 요청 0(Cloudflare 비콘 1 예외) · 모바일 성능 90↑(3초 답 그림은 정지 화면 먼저 · 지연 로딩) · 접근성 · 라벨 겹침 0 · 지면 숫자 = 데이터 파일.

## 3. 원천별 미리 정한 판정

- **PortWatch 인천 품질** — 2025-01 이후 일별 입항 기록 중 0 이거나 빈 날이 **10% 를 넘으면** 「품질 부족」으로 보고, 일일 맥박은 해양수산부 항만별 입출항(월)로 대체한다(지면 이름도 「월 맥박」으로). 판정 숫자는 수집 워크플로가 계산해 `data/collected/portwatch_quality.json` 에 남긴다.
- **PortWatch 추정 교역량** — 모델 추정치라는 것을 숫자 옆에 적는다. 관세청 통계와 다를 수 있다.
- **세계은행 선박 밀도** — 2015-01~2021-02 누적 밀도다. 「지금」의 배가 아니라고 적는다(가짜 실시간 금지).
- **운임지수** — 이용 조건(재배포·가공)을 원문으로 확인하기 전에는 지면에 싣지 않는다.
- **인천공항 국가별 항공통계** — 이용허락범위를 kogl-check 로 확인한 뒤 싣는다. 확인 전에는 관세청 국가별 비중으로만 하늘 아크를 그린다(지금 홈과 같다).
- **OSM 도로 · 등시선** — 도로 등급별 자유 흐름 속도(고속 90 · 간선 60 · 일반 40 · 기타 25 km/h)를 쓰고, 혼잡·신호·상하차 시간은 반영하지 않는다고 지면에 적는다.

## 4. 「평소」의 정의 — 인천항 일일 맥박(데이터 받기 전 · 2026-10-14 추가)

- **최근** = 원천의 마지막 날짜까지 7일. **평소** = 그 앞 91일(13주) 일평균. 같은 요일 수가 같도록 13주로 둔다.
- **판정** — 최근 7일 평균이 평소보다 **10% 넘게 많으면 「평소보다 많다」**, 10% 넘게 적으면 「평소보다 적다」, 그 사이면 「평소 수준」. 문턱 10% 는 수치를 보기 전에 정했다.
- **견줌** — 부산·평택도 같은 식(최근 7일 ÷ 평소)으로 계산해 셋을 나란히 둔다. 절대 척수가 아니라 **자기 평소 대비 비율**로 견준다(항만 크기가 달라서).
- **선종** — PortWatch 선종 다섯(컨테이너·건화물·일반화물·자동차선(RoRo)·탱커)을 그대로 쓴다. 합계 = `portcalls`.
- **「○일 기준」** — 원천의 마지막 날짜를 지면 머리에 적는다. PortWatch 는 며칠 늦게 갱신되므로 「오늘」이라고 쓰지 않는다.

### §4 덧붙임 — 해수부 대조(데이터를 **본 뒤** 넣었다 · 2026-10-14)

- **왜** — PortWatch 인천 일평균이 2026-04 에 절반(10.3척)으로 떨어지고, 평택이 2026-05 부터 두 배(6.8 → 13척)가 됐다. 같은 달 해양수산부 외항 입항(월 · 공식)에는 그런 변동이 없다. §3 품질 규칙(0·빈 날 10%)은 이 변동을 못 잡는다 — 0 이 아니라 **수준이 바뀐** 것이라서.
- **규칙** — 달마다 PortWatch 월합 ÷ 해수부 외항 입항을 내고, **최근 6개 온전한 달 비율의 중앙값**에서 **25% 넘게** 벗어난 달을 「어긋난 달」로 표시한다(그래프에서 흐리게 · 지면에 달 목록). 문턱 25% 는 **수치를 본 뒤** 정했다 — 선커밋이 아니다.
- **판정에 주는 영향** — 어긋난 달이 「평소」 판정 구간(평소 첫날~최근 끝날)에 들면 지면이 판정 옆에 「덜 믿어야 한다」고 적는다. 판정 자체(§4 문턱 10%)는 바꾸지 않는다.
- **한계** — 해수부 「평택.당진」은 당진을 포함한다. PortWatch 「Pyeongtaek」의 범위는 [미확인] — 2026-05 전후 비율 0.5 → 1.0 은 범위가 바뀐 것일 수도 있다.
