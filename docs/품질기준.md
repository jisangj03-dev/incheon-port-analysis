## 0. 홍보 동결

수정이 끝날 때까지 공유·게시 없음. 채널 대기열의 게시 대기 행은 「보류」로 둔다(`docs/채널대기열.md`). 공개 알림 초안(#70 · li-12·th-01)도 게시하지 않는다.

**해당 없음**은 근거와 같이 적는다(예: 정지 지면의 Q7).

## 2. 채점 — 만든 쪽이 채점하지 않는다

- **화면 판정** = 독립 서브에이전트. 받는 것: 네 폭 스크린샷과 이 문서의 §1 표뿐. 만든 경위·작업기록·이전 판정은 주지 않고 **열지 말라고 명시**한다.
- **사실 대조** = 또 다른 독립 서브에이전트. 받는 것: 지면 주소·빌드 결과(HTML)·원자료/파생 파일 경로. 화면 판정 결과는 주지 않는다.
- 칸마다 **통과 / 미달 / 해당 없음 + 근거 한 줄**. 근거 없는 통과는 미달로 센다.
- 채점표 = `docs/채점표_YYYYMMDD.md`(지면 × Q1~Q8).

## 3. 처분

- 전 기준 통과 → **유지**.
- 미달 → 이번에 고칠 수 있으면 고치고 **다시 채점**. 진짜 데이터가 없거나 이번에 못 올리면 **내림**: 메뉴·홈 카드·노트 링크·사이트맵에서 뺀다. 주소는 살려 상위 지면으로 넘긴다(meta refresh + 안내 한 줄 · `layouts/Redirect.astro`).
- 지면 수 목표 없음 — **적게 두되 전부 최상으로.**
- 다시 올리는 것은 진짜 데이터로 다시 설계할 때만.

## 4. 디자인

디자인 시안이 필요하다고 판단한 지면(이번 판단: 홈 첫 화면 · 도구 목록 · 지도 지면)은 **Claude Design 시안**을 받아 만든다. 브리프 = `docs/디자인브리프_20261020.md`(목적 · 실제 숫자 · 화면별 필수 요소 · 참고 수준). 시안이 오기 전에는 구조 · 데이터 정확도 · 움직임 · 내림만 한다(코드가 디자인을 새로 짓지 않는다).
