## 헤드라인

**인천에 등록된 물류창고 480곳 중 60.4%(290곳)가 동 네 곳에 몰려 있다** — 서해구 원창동 94 · 제물포구 항동7가 84 · 영종구 운서동 57 · 제물포구 신흥동3가 55.

면적으로 보면 그림이 달라진다. **연수구는 28곳(5.8%)뿐인데 면적은 21.2%다** — 한 곳 평균 67,174m²로, 인천 평균(18,510m²)의 3.6배다.

소스: `analysis/warehouse_by_gu.csv`·`analysis/warehouse_by_dong.csv`(이 저장소에 공개 · 아래 「재현」).

## 냉동냉장

등록 자료의 **냉동냉장창고면적 열 합은 294,915m²로 전체 면적의 3.3%**다. 그중 61.9%(182,423m²)가 서해구에 있다.

**이 3.3%를 인천의 냉장 보관 능력으로 읽으면 안 된다.** 원자료에서 냉동냉장 면적 열을 채운 것은 **물류시설법 창고(182곳)뿐**이다. 나머지 298곳 — 보세창고, 항만창고, 그리고 식품위생법(47곳)·축산물위생법(55곳)·수산식품산업법(17곳)으로 등록한 식품 계열 119곳(24.8%)까지 — 은 면적이 전부 「타법률창고면적」 한 열에 들어 있고, 그 열은 냉동과 상온을 나누지 않는다. 그러니 3.3%는 **물류시설법 창고 안의 냉동냉장 면적**이다. **인천 전체의 냉장 보관 능력은 이 원천만으로는 알 수 없다 — [미확인]**.

## 한계

1. **좌표가 0건이다.** 주소 정제는 끝났고(고유 주소 454 중 444 = 97.8%), 좌표는 도로명주소 좌표제공 API 운영 키 심사를 기다린다. 그래서 「항만·공항에서 몇 km 안」 같은 거리 주장은 이 페이지에 없다. 좌표 단계의 판정 기준은 데이터보다 먼저 커밋해 두었다 — [`docs/주소좌표_판정기준_선커밋_20260930.md`](../docs/주소좌표_판정기준_선커밋_20260930.md).
2. **10곳(고유 주소 10)은 정제에 실패해 집계에서 빠졌다**(490 → 480). 대부분 지번만 있거나 「등」·블록 표기가 붙은 주소다.
3. **정제 주소가 여러 후보로 나온 56곳(12.3%)은 첫 후보를 썼다.** 맞는 후보인지는 좌표 단계의 표본 대조에서 같이 본다.
4. **상호와 원주소는 공개하지 않는다.** 행 단위 원자료의 재배포 조건(공공누리 유형 등)을 아직 확인하지 못했다. 그래서 이 저장소에는 구·동 집계만 올리고, 상호·원주소가 든 파일은 `.gitignore`로 막았다. 근거법·면적처럼 집계로 묶인 값만 이 페이지에 쓴다.
5. **등록 자료는 「등록된」 창고다.** 물류창고업 등록 대상이 아닌 자가 창고·소규모 창고는 여기 없다.

## 재현

```
python analysis/collect_warehouses.py --src <nlic 「물류창고업 현황」 엑셀에서 만든 CSV> --basis 2026-10-01
python analysis/geocode.py --in analysis/incheon_warehouses.csv --col 소재지 --refine-only   # JUSO_SEARCH_KEY
python analysis/warehouse_map.py --in analysis/incheon_warehouses.csv
```

세 번째 줄이 `analysis/warehouse_by_gu.csv`·`warehouse_by_dong.csv`·`warehouse_by_area.md`를 쓴다. 2026-10-03에 같은 원자료로 정제부터 다시 돌려 **세 파일이 줄바꿈 말고는 커밋본과 한 글자도 다르지 않음**을 확인했다(정제 444/454 재현). 원자료 해시는 `analysis/incheon_warehouses_sources.csv`.
