# 인천항 물류 데이터 분석

공공데이터를 기반으로 인천항의 컨테이너 물동량 흐름을 분석하는 정기 리서치 보고서 모음이다. 각 보고서는 **핵심 요약 → 분석 결과(차트·표) → 해석 → 한계·후속** 구조로, 데이터 출처와 정밀도 한계를 함께 밝힌다.

  → [보고서 전문 보기 →](reports/report_08_관세청_인천항_수출입신고.md)

> #01이 "공컨 비중이 높다"는 관찰을 제시하고, #02가 전체 물동량 대비 28.8%라는 비율로 검증했으며, #03이 그 불균형의 방향(85.1% 수출 방향)을 규명했고, #04가 이 구조가 2022~2025년 48개월 내내 지속됨을 확인했으며, #05가 전체에서 공컨을 빼면 적컨이 수입으로 쏠린다는 거울상(공컨 수출 쏠림의 반대)을 확인했고, #06이 규격(크기) 축을 처음 열어 수입 공컨은 40ft에 쏠리고 수출 공컨은 혼합 구성이라는 비대칭이 48개월 중 42개월에서 성립함을 확인했으며, #07이 그 결론들을 **그 데이터 밖에 놓아** 2026년 상반기로 표본외 검증했으며(기준 4개 사전 커밋, 전부 PASS), #08이 처음으로 **다른 기관의 다른 신고 체계**를 열어 #05의 「적컨은 수입」을 부호 수준에서 교차 확인했다 — 관찰→검증→규명→지속성→수지→규격→표본외 검증→**타 기관 교차 확인**.

## 사용 기술

Python(requests·pandas·matplotlib), 공공데이터 Open API·XML 파싱, hwpx 공표자료 파싱(zipfile+XML), git·GitHub·GitHub Pages, 검증 게이트 설계(기발행 수치 회귀 대조·내적 지문 검산), Wayback Machine을 통한 사멸 API 문서 복원, 이중 실행 환경 교차검증(X-CHECK 대조 게이트), 헤더명 기준 CSV 파싱(연도별 스키마 차이 대응)

## 검증 방식

- 모든 발행 수치는 저장소에 커밋된 수집 원시 CSV에서 재현 가능하다.
- 발행 전 검증 게이트를 통과한다: 기존 발행 수치와의 회귀 대조, 스키마·완결성 확인, 내적 검산(방향합=총합, 규격 환산식).
- 오류는 삭제하지 않고 정정 표기로 남긴다. 판정 기준은 결과 확인 전에 문서로 선커밋한다(docs/ 의 주제검증·정정 기록 참조).

## 데이터 출처

- **공공데이터포털(data.go.kr)** — 인천항만공사 공컨테이너 화물 통계 API
- **인천지방해양수산청** — 「인천항 물동량」 월별 공표 통계 (전체 컨테이너 물동량)
- **관세청** — 「항구·공항별 수출입실적」 (공공데이터포털, #08)

AI가 쓴다는 것이 수치를 지어내도 된다는 뜻이 아니다. **오히려 반대다** —
"AI가 썼다"고 공개하면 독자의 첫 질문이 "그 숫자 진짜냐"가 된다.
원시 데이터와 재현 코드의 공개가 그 질문에 답하는 유일한 수단이고, 그래서 전량 공개한다.
